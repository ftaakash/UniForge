# Dependencies

Every third-party component is listed here with its exact version, source and licence.
Vendored code lives in `third_party/`; licence texts are in `LICENSES/` and ship in the package.
Nothing is downloaded at build time: the repository builds offline.

### What was taken from each upstream

- **Dear ImGui**: `imgui*.cpp/h`, `imconfig.h`, `imstb_*.h`, `LICENSE.txt` and the two backends
  `backends/imgui_impl_win32.*` and `backends/imgui_impl_dx11.*`. Examples, docs, `imgui_demo.cpp`
  and the other backends are left out.
- **ImPlot**: `implot.cpp/h`, `implot_internal.h`, `implot_items.cpp`, `LICENSE`. The demo is left out.
- **GoogleTest**: the top-level `CMakeLists.txt`, `LICENSE`, and the `googletest/` and `googlemock/`
  source trees without their `docs/`, `test/` and `samples/` folders. gmock is not built.
- **Fonts**: `extras/ttf/Inter-Regular.ttf`, `extras/ttf/Inter-SemiBold.ttf` and

### Local modifications

| File | Change | Why | Patch |
|---|---|---|---|
| `third_party/imgui/backends/imgui_impl_dx11.cpp` | With `IMGUI_IMPL_DX11_PRECOMPILED_SHADERS` defined, the shaders come from fxc-generated byte arrays instead of `D3DCompile()` at run time | Removes the run-time dependency on `d3dcompiler_47.dll` and follows spec decision D3 (shaders precompiled with fxc). This is the option upstream itself recommends in the comment above `CreateDeviceObjects()` | `third_party/patches/imgui_impl_dx11_precompiled_shaders.patch` (applies with `git apply` to the upstream tag) |

The HLSL sources in `src/app/shaders/imgui_dx11_{vs,ps}.hlsl` are copied unchanged from the
strings in the upstream backend (MIT).

## Runtime

The packaged executables link the MSVC runtime statically (`/MT`) and depend only on DLLs that
ship with Windows 11. `tools/package.ps1` checks this on every package with `dumpbin /dependents`
against an allow-list. Result for Phase 2:

| Executable | Imports |
|---|---|
| `Launch.exe` | `KERNEL32.dll`, `USER32.dll` |
| `app/UniForge.exe` | `KERNEL32.dll`, `USER32.dll`, `GDI32.dll`, `ADVAPI32.dll`, `SHELL32.dll`, `ole32.dll`, `IMM32.dll`, `d3d11.dll`, `dwmapi.dll` |
| `app/uniforge_cli.exe` | `KERNEL32.dll` |
